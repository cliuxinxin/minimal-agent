## Exact host contracts

- Session detail: existing fields plus resume_available:bool, resume_reason:string|null, restored:bool, storage_warning?:string. Restored interrupted run status is 'interrupted'; message status may be 'interrupted'. Source content/history stay visible. POST /api/sessions/<sid>/continue with {} starts a user-requested continuation from persisted history; no automatic replay. Show '继续处理' on interrupted/error/cancelled/step-limited runs only when resume_available, with reason when blocked. Normal typed follow-up also supported. Can use POST /api/sessions/<sid>/rename {title}, /delete {} and GET /export? optional only if root confirms; do not implement unagreed endpoints.
- Run and assistant message metrics: {model_calls,tool_calls,input_tokens:null|int,output_tokens:null|int,total_tokens:null|int,known_usage_calls,elapsed_seconds,compactions}. SSE run_status may include metrics,phase,last_activity_at,storage_warning. context_compaction events in trace show start/completed/error. Display compact calls/tools/elapsed/token summary, mark partial/unknown usage. Stage indicator reflects real events only.
- POST /api/check-connection {target:'model'|'search',config:{same fields as existing settings POST}} uses unsaved draft, returns {ok:bool,target,checks:[{name,status:'passed'|'failed'|'skipped',message,code?:string}],elapsed_seconds}. Buttons '检查模型连接' and '检查搜索连接'; explain small real API usage before click via nearby text. Never auto-call on page load. Render classified results and preserve current draft/settings; requests must not corrupt later modal state.
- Messages may include artifacts: Array<{id,name,size,change,created_at,run_id,preview_url,download_url}> and sources: Array<{id,title,url,date?:string,read:bool}>. Show cards associated with assistant message. Artifact preview GET /api/artifacts/<id> returns {artifact,content,truncated,diff?,columns?,rows?}; download URL returns immutable attachment. Preview as escaped code/text/CSV table or existing safe Markdown; no generated HTML execution. Downloads ordinary same-origin links. Work file list gets preview/download via metadata only if artifact available; existing attachment behavior remains.
- Source cards show title/domain/date and '已读取原文' vs '搜索摘要'. Use HTTP(S) URLs only, noreferrer. Model uses [S...](actual URL); optionally label unverified source markers when not found in message.sources without claiming semantic verification.
- Tool inventory saved_tools adds enabled,version,previous_version,test_count,input_schema,tests. POST /api/tools/<name>/enabled {enabled:bool}; /rollback {}; /test {} return {tool?:dict,result?:{passed,total,results},...inventory}. Buttons for enable/disable, rollback when previous exists, run tests (tests actually execute local Python, label it). Avoid concurrent mutation of same tool in UI; render errors meaningfully.
